# Atajos con Alt y zoom sólo con Ctrl + rueda

En el navegador del dueño Ctrl+letra ya tiene dueño (Ctrl+G busca en internet), así que los atajos nuevos van con Alt. La excepción es Cmd/Ctrl+K del buscador de pantallas, porque todos lo conocen; por si el navegador lo toma, también está el botón del header. La rueda sola recorre el flyer: el zoom es sólo con Ctrl + rueda.
