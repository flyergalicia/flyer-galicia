# Gestiones: el tablero cuenta menos que la lista, a propósito

El tablero cuenta el período elegido y sólo las acciones con hunter: no entran las bases de datos, lo cancelado ni lo derivado que nadie asignó (eso último sale aparte como aviso, porque no es trabajo de nadie). La lista trae todo, sin período. "Caja de Ahorro" es "Sin paquete": un alta exige paquete y el tablero las separa.

## Consecuencias

Un horario que se pisa lo frena la base (salvo admin o el líder de ese hunter). El hunter nunca cambia el hunter de una acción, ni en las suyas.
