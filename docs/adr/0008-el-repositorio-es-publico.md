# El repositorio es público a propósito

GitHub Pages es gratis sólo con el repo público; privado, se apaga el sitio. Por eso nada personal ni ninguna clave se versiona: `scratchpad/`, capturas de pruebas (`.playwright-mcp/`), copias con datos (`_backup_*`) y presentaciones están en `.gitignore`, los commits van con un autor neutro y la clave pública de Supabase en `web/.env.production` es la única que está en el repo.
